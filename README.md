# CampusTrack — CPIS 358 Assignment 1 (course-only version)

This static website is an educational demonstration, using concepts from the user's supplied course files:
- `1-HTML Lecture Silde 1 - 2023.pptx`: document structure, images, linking, tables, lists, forms.
- `2-HTML Lecture Silde 2 - 2023.pptx`: semantic page elements, form elements, HTML5.
- `3-CSS Part 1.pdf`: inline, embedded, external CSS; positioning, z-index, float, menus, media queries.
- `4-CSS Part 2.pdf`: rounded corners, shadows and colors.
- `5-JavaScript Part 1.pdf`: variables, simple scripts and conditions.
- `6-JavaScript Part 2.pdf`: `if`/`else`, operators and control statements.
- `7-JavaScript Part 3.pdf`: functions, DOM, getElementById, events.
- `Complete JS example.html`: examples of DOM textContent, createElement, appendChild and HTML events.
- Assignment 1 instructions: image map on every page, group GitHub participation, report.

Pages: index.html, planner.html, courses.html, login.html, signup.html, about.html.

## Start
Open `index.html` in any browser. All links are relative, so the website also works on GitHub Pages.

## What JavaScript does
- Home: displays messages on button clicks (embedded and external JavaScript).
- Planner: creates task list items with DOM methods and updates a number. Tasks are only in page memory. They are not saved.
- Login / Sign Up: demonstration form checks. No authentication, server or account creation.
