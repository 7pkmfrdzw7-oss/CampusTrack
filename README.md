# CampusTrack — CPIS 358 — Assignment 2

Static student study planner project, continuing Assignment 1.

## Features (from the course lectures)
- HTML pages: Home, Planner, Courses, About Us, Login, Sign Up
- Inline, internal and external CSS; classes, borders, shadows, menus, z-index
- Image maps on each page linking to About Us
- JavaScript: changing picture src, text via innerHTML and CSS style
- JavaScript form validation (onsubmit, onblur, if/else) on Login and Sign Up
- JavaScript dynamic elements with createElement, appendChild and a for loop
- Functions and onclick events

## Files
- index.html, planner.html, courses.html, login.html, signup.html, about.html
- assets/styles.css — CSS style sheet
- assets/app.js — external JavaScript
- assets/study-banner.png and assets/study-plan.png — dynamic picture demo

Open index.html in a web browser or publish the contents of this folder to GitHub Pages.

**Security:** Login and Sign Up are demonstration forms only. No server, storage, or real authentication. Do not type a real password. Planner tasks reset when the page is refreshed.
